# TermiGraph 🧮📊
A terminal-based engineering calculator written in C that supports advanced mathematical functions and can plot function graphs using clean ASCII art.

---

## 🚀 Overview
**TermiGraph** is a lightweight yet powerful engineering calculator built entirely in C.  
It runs inside the terminal and provides both mathematical computation and function plotting capabilities without relying on external libraries.

The interface is enhanced with styled ASCII art to create a visually appealing terminal experience.

---

## ✨ Features

- ✅ Standard arithmetic operations
- ✅ Engineering math functions:
  - `sin(x)`
  - `cos(x)`
  - `tan(x)`
  - `log(x)`
  - `exp(x)`
  - and other math library functions
- ✅ Function plotting directly in the terminal (ASCII graph rendering)
- ✅ Calculation history saved locally
- ✅ Clean and styled terminal UI
- ✅ No external dependencies (only standard C libraries)
